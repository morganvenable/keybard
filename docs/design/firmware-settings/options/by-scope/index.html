Settings, organized by where each setting lives

One option for the Settings reckoning, revised in round 2. Settings is one panel with three groups, named for what each acts on: this keyboard (firmware, identity, backups), this browser (app preferences) and Keybard itself. Configuration of the layout and the devices lives in the main editor, not here. Mockups use Keybard's real tokens and fixed brand colors; the page follows your system theme and the button toggles it.

Round 2. Settings holds only app preferences and board/firmware management. Typing, Pointing, Lighting and Scanning and power have left Settings for the main editor (settings-structure.md section 2). Combo and leader timing stay in their panels, with no gears. Backups moved into "This keyboard". Firmware screens follow the round-2 flow ("Afterwards" is chosen up front, then the update runs hands off). Each change is listed in mapping.md.

1. The structure

The group a page sits in says what it acts on: the board, this browser, or Keybard itself. About and the four Settings tabs fold into this one panel. Nothing in it configures the layout or the devices.

Left Settings for the main editor: Typing behavior (new rail item), mouse key speeds (Mouse Keys panel), combo and leader timing (their panels), pointing (Pointing Devices), finger clusters (new Clusters rail item), layer colors (layer header dot), scan and idle tuning (Scan Lab).

2. Getting there, with an update available

Settings stays in the rail footer and is the only settings entry. When Keybard carries a firmware newer than the board's, a dot appears on Settings and a pill on the Firmware row. They replace today's 6-second chip and the note that covers the layer tabs. About leaves the rail. Key size and panel position move from the editor's corner to Appearance. The rail gains the two new editor homes, Typing behavior and Clusters.

3. Every page

One row idiom everywhere: label on the left, control in a fixed right-hand column. One switch (the blue one QMK Settings already uses), one select, one segmented control, one number box. Each page has a breadcrumb naming its group, so the scope stays visible after drilling in.
