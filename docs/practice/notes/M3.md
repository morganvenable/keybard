## Deviations from the spec, and why

1. **A new Drill starts on Weakest**, not All. The spec leaves the default open; All on every layer of the default keymap is 68 characters (a four-row key strip and a focus that takes dozens of lessons to come round). Changing any scope control takes the user's choice from there.
2. **Whitespace is never a drill character**, and neither are capitals. Space separates every token anyway, and keybr's text input can't drill Enter or Tab as characters; capitals come with the Capitals slider in Guided and Words. So on the default keymap **Thumbs** changes nothing (no lesson character's target is a thumb key); it matters on keymaps that bind letters or symbols to thumbs. Prerequisites on the thumbs are always allowed, as the spec says.
3. **Unlock order across classes**: within a tier, letters come before digits before symbols, then frequency. keybr's letter frequencies and its programming-symbol frequencies are not on one scale, so `;` (tier 1 on the default keymap) would otherwise lead every mixed scope.
4. **Drill this key's scope**: the character's cluster neighbors on its own layer; when that leaves fewer than 3 characters, the cluster's characters on every layer. Its focus stays on the chosen character until it reaches the target, then moves to the weakest. The type row reads `! and its cluster`. Any change in the Drill section ends it (layer pills and group tiles show nothing selected while it is on). On a capital it drills the lowercase letter when that is the same key on the same layer, since capitals are never drill characters; a character with nothing to drill (Space, a capital typed from another key) has no **Drill this key** in P5.
5. **Progress tracks every character the keymap types** (spec §6.1 keeps stats per character but keybr's map only held the lesson's letters). This is what lets Weakest and Drill this key work from any lesson type and keeps stats across type switches; the snapshot rule adds "covers every tracked character" (§6.8), and the engine version moved to `practice.2`, so the first load after this update replays once. The Characters table now lists the language letters always and other characters once practiced (M1b deviation 12 closed).
6. **Drill words** come from the letters Guided has unlocked for the profile (at least six) plus the scope's letters, as the mockups show (`(#sad)`, `#lad!`). Short words are dictionary words of up to 5 letters when at least 15 fit, else phonetic pseudo-words.
7. **Number shape**: keybr's numbers lesson has no `1,204` or `8.5` shapes (the spec's example); Benford numbers are keybr's digit groups, restricted to the digits in scope, each holding the focused digit.
8. **Custom text**: untypeable characters are removed, not replaced (`résumé` → `rsum`), as the spec says "stripped". Lowercase and Letters only keep keybr's defaults (on). A text with nothing typeable shows **Nothing to type in this text** with **Edit text** (not in the spec; keybr would fill the lesson with `?`).
9. **Nothing to drill keeps the type row** above the well (M-10's frame does), so another lesson type is one click away; the strip and metrics give way to the well.
10. **Key overrides**: only overrides with no trigger mods or Shift alone become paths (others need Ctrl, Alt or GUI, which type no lesson character); negative mods count only for Shift; `suppressed_mods` decides whether the replacement is typed shifted. Enabled is the file's `enabled`, else options bit 7.
11. **Combos**: each keycode of a combo is found at its cheapest position in each layer state (a keycode bound twice gives one path, not every combination); in a held state a combo is new only when one of its keys comes from the held layer. Combo output is not delayed (QMK sends it when the last key goes down). Timing still divides by 1 + new prerequisites: a combo counts as one press, a double tap too (§6.5 says nothing about chords).
12. **Layout 2** stores the other combo targets in one extension word per combo hit rather than in w2 (6 bits can't hold indices); a lesson without combo or double-tap hits stays layout 1. A hit whose observed key is not one of its path's targets (the rule-3 OS-layout case, M2 deviation 2) unpacks with that key in its path.
13. **Words list size defaults to 200** (keybr: 1000), the value the spec's scope example and M-16 show.
14. **Number format row** is titled Number format with a Benford toggle and no value line.
