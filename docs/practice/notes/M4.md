## Deviations from the spec, and why

1. **Where heatmap numbers come from.** Speed and Accuracy of a key are its character's (keybr's filtered speed and confidence), so the heatmap matches the Characters table as the acceptance asks; Errors and Usage are physical and come from the key's own samples. Keys that type whitespace or untracked characters (Space, Enter) use their key samples for every metric.
2. **Errors** = (misses expected on the key + strays pressed on it) / (hits + misses + strays). The spec's "share of its presses" leaves the denominator open; a key hit only by mistake reads 100%.
3. **Usage** counts a key's presses as hits + strays + prerequisite presses (the reach samples), so Shift and layer thumbs have usage too. Quartiles are taken over the keys shown on the heatmap, and separately over the Fingers and Thumbs cells.
4. **A key transparent on the chosen layer** shows no data there: its character belongs to the layer it falls through to.
5. **Printed values round toward "needs work"**: speed and accuracy down, errors up, so a key just short of target never prints the target value. One formatter pair (`formatSpeedDown`, `formatPercentDown` in `ui/format.ts`) prints a character's speed, best, accuracy and confidence everywhere they sit beside a target: the heatmap, the Characters table, P5 and the key strip's tips, so all of them agree (the heatmap prints whole WPM, the table one decimal). Other figures (Summary, the last lesson, Layers, History) still round to nearest. The Speed scale prints whole numbers (`< 13 · 13–19 · 19–25 · ✓ ≥ 25 wpm`).
6. **Thumbs' layer reach** shows for any thumb held as a prerequisite at least as often as it was tapped (Shift too), not only layer holds.
7. **P5 aggregate numbers**: Best is the group's best per-lesson speed, Samples its hits, Confidence its speed over the target, To target `—`; a layer-hold thumb shows **Layer reach** in place of Speed. Its sparkline is the group's per-lesson speed.
8. **Drill this group** shows only when the group has at least 3 characters Drill can drill (otherwise the drill would open on Nothing to drill). A group's results are stored with `x.scope.group = 'keys'` like Drill this key, and History reads them `Drill · Chosen keys`. The type row reads the group's name (`DrillSettings.name`).
9. **Pressed instead and P5's layer reach come from the stored events** (results don't carry them), read once per lesson and cached; lessons whose events were pruned (beyond OWNER_Q5's 1,000) add nothing. The Lessons key strip reads them only when a popover opens, so typing never waits on the store.
10. **P5 Inferred only** is per character: every lesson in scope containing it had no observed hit. Results don't keep per-character confidence.
11. **Stray window**: strays are the unused presses between the previous attributed step and this one; presses before the lesson's first keystroke and after its last are not between two steps and are ignored.
12. **The OS layout notice** shows while Live · USB is *available*, not only while the text has focus, so it stays while its select is open. The layout's short name drops "English (…)": `US`, `UK`; others use Keybard's label.
13. **Reset** deletes the profile's results, events and snapshot in one transaction (`PracticeStore.clearProgress`) but keeps the profile (Start does not come back). Its confirm also prints `N lessons will be deleted` (the spec gives that line only to Replace), and a failure shows `Reset failed` in the Reset row, as Export and Import do.
14. **Import and Reset are unavailable when a newer Keybard wrote the profile** (read-only, §8.6) as well as with Storage off, with the value `Not available · progress was saved by a newer Keybard`.
15. **After an import** the Import row reads `N lessons imported` (not in the spec).
16. **Key.tsx gained an optional `footer` strip** (no tint, styled by `footerClassName`) for the heat values; no existing caller changes.
17. A heatmap key that types a character with no samples is still a button (P5 shows **No samples yet** and Drill this key); keys that type nothing and have no samples (modifiers, navigation) are not buttons.
18. **Heat legends are plain text on every key** (§5.0.2: no header strip, no tinted bottom strip). A key that types no character reads `MO 1` for a layer key, and otherwise Key.tsx's center label (an LT key its tap key, `Enter`), so the layer part of an LT key is not on its face; Thumbs names it. Icons such as a mouse key's keep an untinted header in the face's text color.
19. **A Layers row's group is every character whose primary path is on the layer** (`charsOnLayer`), practiced or not, for its chips and Drill this group, as Fingers and Thumbs groups take every character on their keys. The Characters column still counts only the characters with samples.
20. **A heatmap key's P5 for a key that types no character** (Space, Enter) is scoped to the shown layer throughout: totals, sparkline and Best.

## Needs Mule testing

Use the Mule, never the daily-driver half.

1. **Strays**: in a live lesson, brush a letter key between two characters without typing it into the lesson (for example press it while Caps Lock drops keystrokes, or a Space before a word). Progress → Keyboard → Errors shows that key with a value; P5 for its character is unchanged.
2. **OS layout mismatch**: set Keybard's OS layout (Settings → International Keyboards) to German while the computer types US, then type a lesson with `y` and `z`: the notice **Typed characters don't match German layout** shows within about 5 eligible keystrokes; choosing English (US) in its select restarts the lesson and the notice goes. Then a Layer 1 symbol drill on the correct layout: no notice.
3. **Layer reach**: type a Layer 1 symbol drill through MO(1) and through LT1. Progress → Thumbs shows ms values on R-thumb T5 and L-thumb T1; Layers shows Reach for Layer 1; P5 for `!` shows Layer reach and no Inferred chip.
4. **Pressed instead, observed**: type `q` for `!` a few times live: P5 for `!` lists `q` with **wrong layer** and no Inferred chip.
5. **Export, reset, import** on the test site with real history (IndexedDB), and Paranoid's Export (a download from the single file).
