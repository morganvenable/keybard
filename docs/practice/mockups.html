Visual language alignment

Practice and Overlay add no stylesheet with colors. Every surface below is an existing Keybard component or class string, or one of the new components listed with the reason no existing one fits (spec §5.0.3, Q8). Revision 3 also gives Keybard one meaning per color, app-wide (D13).

Color roles

Layer color = “on layer N”

Key faces on the Practice board and strip, layer-pill dots and the layer underline. User data. Never drawn on a heat face.

Ink = “you, now”

Next-key ring, pressed-now face on the Practice board, caret, focus rings, active pills and tiles.

Select (new, kb-select) = “the one you picked”

Blue ring with an offset, plus a light blue face on editor keys. Selected key, hover, drop target, Matrix Tester pressed, the opener of a Key popover, the preview key chosen for Familiar bindings.

Pending (new, kb-pending) = “changed, not sent”

Amber 2 px dashed border on a key with unsent edits (also when it is selected), the Apply outline, the Saving dot in the Overlay panel.

Red = error, destructive, wrong

Wrong-key border, the error tint and wavy underline, error lines and notices, Reset / Replace / Delete. A selection, a pending edit and a correct press are never red.

Brand green = the one forward action

Start, Connect board, Download for Windows. On a key face green is only layer 0’s color.

Heat = “needs work”

Red → orange → yellow on Progress heat faces only, for keys still short of target; keys at target are plain with a check. Usage uses a blue ramp.

Tokens in use

Themed tokens show light and dark halves. Data colors (layer faces, heat faces) are identical in both themes; key faces are user data (README.md:144-150).

New components (spec §5.0.3, each needs your approval)

N-1 SegmentedControl (sm, md)

OnOffToggle’s track and segments with any labels, role="radiogroup". Lesson type on the page (md), WPM·CPM, Show·Hide, Hands, metric, period, Merge·Replace, Off·Flash·Fade, preview Background.

N-2 ToggleChipGroup

Multi-select chips in the path-chip shape, aria-pressed. Drill directions. The 2S chip appears only with a 6-key cluster.

N-3 StatCell

12 px muted label, 28 px semibold tabular value that never wraps, delta in ink led by ▲/▼.

N-4 Status slot

The right half of the fixed 48 px type row, empty while idle. Every banner and notice appears there, one at a time, so the text never moves.

N-5 Typing surface

Pending muted-foreground, typed kb-ink, errors kb-red with a wavy underline, a 2 px ink caret, a solid layer underline on pending characters only.

N-6 Next-key ring, alternative, step badge

Ink ring with a page offset; dashed ink outline for an alternative path; a small ink badge so a key keeps its own header.

N-7 Pressed-now face

bg-kb-active while held. Ink, not the select role: the board is not selectable, and a 100 ms press over a saturated face needs the strongest contrast.

N-8 Confidence bar

Track bg-muted, fill bg-kb-ink.

N-9 Heat faces

kb-red / kb-orange / kb-yellow for far / mid / near, plain face with a check at target, blue ramp for Usage, dashed for no data. No layer color. Values in the footer strip.

N-10 Line chart, sparkline

Speed solid kb-blue, accuracy dashed kb-purple, target dotted ink, labels at the line ends.

N-11 Today ring

36 px ring, kb-primary on a bg-muted track.

N-12 Fingers grid, direction glyph

64 × 40 heat cells; every row label carries a 3 × 3 glyph with its direction in ink.

N-13 Inferred chip

Path-chip shape, muted text; a focusable button whose tooltip gives the reason.

N-14 Uncalibrated marker

Full layer face, empty bar, “?” in the header strip.

N-15 Color field

28 px swatch button showing the user’s color, hex as the row value; popover with brand swatches, white and black, a hex Input and “More colors…”.

N-16 Overlay preview card

Surface card whose canvas paints a desktop stand-in background (Light, Dark, Busy) behind the user’s overlay; footer with the source and a Background SegmentedControl.
