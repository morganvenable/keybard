Open the Windows companion and copy its browser pairing token. Paste it below. Keep the companion running while using app contexts.

This draft reports only the focused Onshape origin, such as https://cad.onshape.com. It does not read model contents, keystrokes, document names, or full URLs. Other tabs clear the Onshape context. Incognito windows are excluded.

Supports Chrome and Edge on Windows. After installing or updating this extension, reload any already-open Onshape tabs.
